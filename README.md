# DataStructs

My implementations of data structures and algorithms, mostly in C#, with some C++ (2020 to 2024). Each folder is its own project.

## What's here

- **Lists, stacks and queues**: `Linked_lists`, `circularLinkedList`, `TestLinkedListForCircularity`, `Stacks`, `Stack2`, `Queue`, `Queue2`, `SkipList`
- **Trees**: `BST Trees`, `BSTrees`, `Balanced_Trees`, `RedBlack` (with tests and a visualizer), `RedBlackTree`, `HeapTree`, `Tries`, `BurstTrie`
- **Hashing and caching**: `HashMap`, `BloomFilter`, `LRUCache`
- **Sorting**: `MergeSort`, `MergeSort2`, `QuickSort`, `QuikSort`, `KWayMerge`
- **Graphs**: `Un-Graphs` (undirected), `WD-Graphs` (weighted directed), `UnionFind`, `UnionFindRevisiting`, `Pathfinding`, `PathfindingVisualizer`, `PathfindingVisualiserV2`
- **Other**: `Huffman` (Huffman coding), `FiffteenPuzzleGame` and `FifteenPuzzleV2` (15 puzzle), `Recursion`, `delegates`
- **!C++**: linked lists, a BST, a heap, quicksort and smart pointers in C++
